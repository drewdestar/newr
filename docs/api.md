# newr API reference

Generated by `newr docs` (newr 0.2.0). Do not edit by hand: edit the `///` doc comments in the source (or the `doc` strings in `compiler/modules.py` for stdlib members) and regenerate.

The standard library, versioned with the language (SPEC.md section 12). Core modules are available on every target; named modules work by name without an import. `json` and HTTP `fetch` are v1.1, not v1 (section 12.3).

## Core builtins

Available without an import.

### `print`

`print(expr, ...)`

Writes the values space-separated plus a newline to stdout.

### `input`

`input(prompt: str = "") -> str`

Reads one line from stdin (blocking). The prompt is optional.

### `len`

`len(x) -> int`

Length of a str (characters), list, dict, or set.

### `str`

`str(x) -> str`

Converts int, float, or bool to its text form.

### `int`

`int(x) -> int`

From str (parses, throws on invalid) or float (truncates).

### `float`

`float(x) -> float`

From str or int.

### `bool`

`bool(x) -> bool`

From str ("true"/"false") or int (0 is false).

### `min`

`min(a, b) -> T`

The smaller of two same-type numbers (or strs, lexicographic).

### `max`

`max(a, b) -> T`

The larger of two same-type numbers (or strs, lexicographic).

### `abs`

`abs(x) -> T`

Absolute value of a number.

### `round`

`round(x) -> int / round(x, n: int) -> float`

Rounds to an int, or to n places as a float.

### `range`

`range(n) -> list[int] / range(a, b) -> list[int] / range(a, b, step) -> list[int]`

Half-open list [a, b) of ints.

### `set`

`set(list[T]) -> set[T]`

Builds a set from a list. There is no set literal in v1.

### `ok`

`ok(v) -> Result[T, error]`

Builds a successful Result value.

### `err`

`err(e) -> Result[T, error]`

Builds a failed Result value.

### `log`

`log expr` (statement) / `log.info/warn/error(msg)`

Writes to the program's logger. `log` is a statement, not a call, and `log.info` / `log.warn` / `log.error` are the levelled forms (SPEC.md section 12.1). `t()` for i18n lives in the discord module (SPEC.md section 15), not here.

## db module (SPEC.md section 12.5)

SQLite, sync, one connection per handle. The handle is an `int` (fd style). `db.query` returns a typed struct list, resolved from the expected type at the call site. Every db call throws on failure.

### `db.open`

`open(path: str) -> int`

Opens a SQLite database file and returns a connection handle (an int, fd style). Creates the file when missing; throws when the parent directory does not exist. `":memory:"` opens a private in-memory database.

### `db.exec`

`exec(handle: int, sql: str, args...) -> int`

Runs exactly one statement and returns rows affected (0 for DDL). Values bind to `?` placeholders, one argument per placeholder, in order. Throws on failure.

### `db.query`

`query(handle: int, sql: str, args...) -> list[RowStruct]`

Runs a SELECT and returns the rows as a typed struct list. The call site must carry the expected type, for example `let todos: list[Todo] = db.query(...)`. Columns match struct fields by name; a missing column or a value that cannot convert throws at runtime.

### `db.begin`

`begin(handle: int)`

Begins an explicit transaction (BEGIN IMMEDIATE). A second begin without commit or rollback is an error.

### `db.commit`

`commit(handle: int)`

Commits the open transaction.

### `db.rollback`

`rollback(handle: int)`

Rolls the open transaction back.

### `db.last_id`

`last_id(handle: int) -> int`

The last AUTOINCREMENT id on this handle.

### `db.close`

`close(handle: int)`

Closes the handle. Using a closed handle throws.

## http module (SPEC.md section 12.6)

HTTP server plus fetch client, sync. Routes are exact-match only. The request and response are user-declared structs, validated by field shape. Fetch returns a typed HttpResponse struct, resolved from the expected type at the call site. Every http call throws on failure. Fetches are allowlisted (newr.json `http_allowlist`, default localhost only).

### `http.route`

`route(method: str, path: str, handler: fn) -> none`

Registers one exact-match route. The method must be one of GET, POST, PUT, PATCH, DELETE, HEAD, OPTIONS (uppercase); the path must start with "/". The handler is a lambda taking one request struct (method, path, headers, body, query) and returning a response struct (status, headers, body). Two routes with the same method and path are an error. A request with no route returns 404 with an empty body.

### `http.serve`

`serve(port: int) -> none; serve(port: int, host: str) -> none`

Serves the registered routes forever, until the process is killed. Binds 127.0.0.1 by default; an explicit host binds that host instead ("0.0.0.0" listens on all interfaces). Port 0 means the OS picks an ephemeral port, and the server prints `listening on <host>:<port>` with the real port as its first line. Put `serve` last: it never returns.

### `http.get`

`get(url: str) -> HttpResponse; get(url: str, timeout: int) -> HttpResponse; get(url: str, timeout: int, headers: dict[str, str]) -> HttpResponse`

Fetches a URL with GET and returns the response as a typed struct (status, headers, body), resolved from the expected type at the call site, for example `let resp: HttpResponse = http.get(url)`. The timeout is whole seconds (default 10) and covers the whole request. The URL host must be on the allowlist (newr.json `http_allowlist`, default localhost only). Throws on failure; use try/catch to handle it.

### `http.post`

`post(url: str, body: str) -> HttpResponse; post(url: str, body: str, timeout: int) -> HttpResponse; post(url: str, body: str, timeout: int, headers: dict[str, str]) -> HttpResponse`

Fetches a URL with POST, sending the body as given, and returns the response as a typed struct (status, headers, body), resolved from the expected type at the call site. Sets `Content-Type: application/json` unless the program sets one. The timeout is whole seconds (default 10). The URL host must be on the allowlist. Throws on failure.

### `http.request`

`request(method: str, url: str, body: str) -> HttpResponse; request(method: str, url: str, body: str, timeout: int) -> HttpResponse; request(method: str, url: str, body: str, timeout: int, headers: dict[str, str]) -> HttpResponse`

The generic fetch primitive: any method (GET, POST, PUT, PATCH, DELETE, HEAD, OPTIONS), any URL, a body sent as given. Returns the response as a typed struct (status, headers, body), resolved from the expected type at the call site. Sets `Content-Type: application/json` when a body is sent and the program sets none. The timeout is whole seconds (default 10). The URL host must be on the allowlist. Throws on failure.

## json module (SPEC.md section 12.7)

Typed JSON. `encode` takes any encodable value (struct, list, dict, scalar, or nullable of those); `decode` takes its type from the call site. Enums are not encodable in M8b. Floats encode as their shortest round-trip decimal, with ".0" for integral floats.

### `json.encode`

`encode(value) -> str`

Encodes a value as JSON text. The value may be a struct, a list, a dict, a str, an int, a float, a bool, or a nullable of any of those (none encodes as `null`), nested recursively. Structs encode as objects, field names as keys, in declaration order; nullable fields that are none encode as `null` (they are not omitted). Enums are NOT encodable in M8b. Floats encode as their shortest round-trip decimal, with ".0" for integral floats (1.0 encodes as "1.0"). Ints encode as exact decimal, including int64.

### `json.decode`

`decode(text: str) -> T`

Decodes JSON text into the expected type at the call site, for example `let todos: list[Todo] = json.decode(text)`. The expected type may be a struct, a list, a dict, a str, an int, a float, a bool, or a nullable of any of those. A JSON `null` decodes to `none` only for a nullable expected type. Struct fields match by name; a missing field throws, an extra field is ignored. A JSON number with a fraction into an `int` field throws; a JSON integer into a `float` field is fine. Trailing data after the JSON value throws, and an empty string throws. Duplicate keys: last wins.

## ui module (SPEC.md section 12.8)

One small widget set. Constructors build an immutable widget tree; `render` returns a deterministic HTML string; `show` opens a native window (or writes the HTML file on js and dart); `run` is the interactive loop, re-invoking a view function after each event, with state in the db module or an http backend. A handler never assigns to a captured variable (that assignment is a silent no-op).

### `ui.text`

`text(s: str) -> Widget`

A label with plain text. The render core HTML-escapes the text. Renders as `<p>text</p>`.

### `ui.button`

`button(label: str, on_tap: fn() -> none) -> Widget`

A button with a label and a tap handler. The handler is a let-bound lambda or an inline single-expression lambda (a block-body lambda cannot be written as a call argument, E1001). The handler takes no arguments and returns none. Renders as `<button data-action="N">label</button>`, where N is the button's 0-based index in pre-order traversal of the tree.

### `ui.input`

`input(placeholder: str, value: str, on_change: fn(str) -> none) -> Widget`

One line of text with a placeholder, the current value, and an on-change handler receiving the new text. The view supplies the current value from state on every re-render; there is no two-way binding. Renders as `<input placeholder="..." value="..." data-input="N">`, where N is the input's 0-based index in pre-order traversal of the tree.

### `ui.list`

`list(items: list[Widget]) -> Widget`

A vertical list of widgets, normally rows. Each child is wrapped in an `<li>`. Renders as `<ul><li>...</li>...</ul>`.

### `ui.image`

`image(url: str) -> Widget`

An image by URL. The URL must be a string literal starting with `http://` or `https://`. `ui.render` emits an `<img>` tag and never fetches the URL, so render tests need no network. A native window shows an empty placeholder when the load fails. Renders as `<img src="..." alt="">`.

### `ui.row`

`row(children: list[Widget]) -> Widget`

Horizontal layout: the children in a row, in order. No spacing, alignment, or sizing arguments in v1. Renders as `<div data-layout="row">...</div>`.

### `ui.column`

`column(children: list[Widget]) -> Widget`

Vertical layout: the children in a column, in order. No spacing, alignment, or sizing arguments in v1. Renders as `<div data-layout="column">...</div>`.

### `ui.render`

`render(root: Widget) -> str`

Renders a widget tree to a deterministic HTML string. Pure: no window, no network, no side effects. The same tree renders to the same bytes on every target and every run (SPEC.md section 12.8 pins the byte format). This is the conformance-testable core of the module.

### `ui.show`

`show(root: Widget) -> none`

Opens the tree in a native window where a toolkit exists (py, java, kt, cs, rs) and blocks until the window closes. On js and dart it writes the rendered HTML to a file next to the program and prints the path, then returns. At most one of `show` and `run` may be called in a program; a program has one window.

### `ui.run`

`run(view: fn() -> Widget) -> none`

The interactive loop. Takes a view function, not a tree: the runtime calls the view, renders the tree, dispatches one event to its handler, then calls the view again and re-renders. State lives outside the tree (in the db module or an http backend); a handler never assigns to a captured variable (that assignment is a silent no-op, SPEC.md section 12.8). The loop ends when the window closes. On js and dart it renders once and returns; the interactive loop is a documented no-op on those targets.

## Methods (SPEC.md section 12.4)

Methods on values. The receiver type is shown first.

### `str`

- `str.upper() -> str`: Uppercase copy.
- `str.lower() -> str`: Lowercase copy.
- `str.strip() -> str`: Copy with leading and trailing whitespace removed.
- `str.split(x: str) -> list[str]`: Splits on the separator.
- `str.join(x: list[str]) -> str`: Joins a list of strs with this string between them.
- `str.contains(x: str) -> bool`: Whether the string contains the argument.
- `str.starts_with(x: str) -> bool`: Whether the string starts with the argument.
- `str.ends_with(x: str) -> bool`: Whether the string ends with the argument.
- `str.chars() -> list[str]`: One Unicode code point per element.

### `list[T]`

- `list[T].append(x: T) -> none`: Appends an element.
- `list[T].contains(x: T) -> bool`: Whether the list contains the element.
- `list[T].get(x: int, a: T) -> T`: Element at the index, or the default when out of range.
- `list[T].len() -> int`: Number of elements.

### `dict[str, T]`

- `dict[str, T].keys() -> list[str]`: Keys in insertion order.
- `dict[str, T].get(x: str, a: V) -> V`: Value for the key, or the default when absent.
- `dict[str, T].contains(x: str) -> bool`: Whether the dict has the key.

### `set[T]`

- `set[T].add(x: T) -> none`: Adds an element.
- `set[T].remove(x: T) -> none`: Removes an element.
- `set[T].contains(x: T) -> bool`: Whether the set contains the element.

### `T?`

- `T?.is_some() -> bool`: Whether the value is present.
- `T?.is_none() -> bool`: Whether the value is absent (none).
- `T?.unwrap() -> T`: The value, or an error when absent.

### `Result[T, E]`

- `Result[T, E].is_ok() -> bool`: Whether the Result is ok.
- `Result[T, E].is_err() -> bool`: Whether the Result is err.
- `Result[T, E].unwrap() -> T`: The ok value, or an error when err.
- `Result[T, E].unwrap_or(x: T) -> T`: The ok value, or the default when err.
