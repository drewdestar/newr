# newr API reference

Generated by `newr docs` (newr 0.2.0). Do not edit by hand: edit the `///` doc comments in the source (or the `doc` strings in `compiler/modules.py` for stdlib members) and regenerate.

The standard library, versioned with the language (SPEC.md section 12). Core modules are available on every target; named modules work by name without an import. `json` and HTTP `fetch` are v1.1, not v1 (section 12.3).

## Core builtins

Available without an import.

### `print`

`print(expr, ...)`

Writes the values space-separated plus a newline to stdout.

### `input`

`input(prompt: str = "") -> str`

Reads one line from stdin (blocking). The prompt is optional.

### `len`

`len(x) -> int`

Length of a str (characters), list, dict, or set.

### `str`

`str(x) -> str`

Converts int, float, or bool to its text form.

### `int`

`int(x) -> int`

From str (parses, throws on invalid) or float (truncates).

### `float`

`float(x) -> float`

From str or int.

### `bool`

`bool(x) -> bool`

From str ("true"/"false") or int (0 is false).

### `min`

`min(a, b) -> T`

The smaller of two same-type numbers (or strs, lexicographic).

### `max`

`max(a, b) -> T`

The larger of two same-type numbers (or strs, lexicographic).

### `abs`

`abs(x) -> T`

Absolute value of a number.

### `round`

`round(x) -> int / round(x, n: int) -> float`

Rounds to an int, or to n places as a float.

### `range`

`range(n) -> list[int] / range(a, b) -> list[int] / range(a, b, step) -> list[int]`

Half-open list [a, b) of ints.

### `set`

`set(list[T]) -> set[T]`

Builds a set from a list. There is no set literal in v1.

### `ok`

`ok(v) -> Result[T, error]`

Builds a successful Result value.

### `err`

`err(e) -> Result[T, error]`

Builds a failed Result value.

### `log`

`log expr` (statement) / `log.info/warn/error(msg)`

Writes to the program's logger. `log` is a statement, not a call, and `log.info` / `log.warn` / `log.error` are the levelled forms (SPEC.md section 12.1). `t()` for i18n lives in the discord module (SPEC.md section 15), not here.

## Core modules

### `math.sqrt`

`sqrt(x: float) -> float`

Square root.

### `math.floor`

`floor(x: float) -> int`

Rounds down to the nearest int.

### `math.ceil`

`ceil(x: float) -> int`

Rounds up to the nearest int.

### `math.pi`

`pi: float`

The constant pi.

### `math.e`

`e: float`

The constant e.

### `time.now`

`now() -> int`

Current time as unix seconds.

### `time.format`

`format(ts: int, fmt: str) -> str`

Formats a unix timestamp with one of the fixed formats (not strftime).

### `random.int`

`int(a: int, b: int) -> int`

A random int in [a, b].

### `random.choice`

`choice(list[T]) -> T`

A random element of a list.

### `random.shuffle`

`shuffle(list[T])`

Shuffles a list in place.

### `file.read`

`read(path: str) -> str`

Reads a UTF-8 text file. Throws on failure.

### `file.write`

`write(path: str, content: str)`

Writes a UTF-8 text file, replacing it. Throws on failure.

### `file.append`

`append(path: str, content: str)`

Appends to a UTF-8 text file. Throws on failure.

### `file.exists`

`exists(path: str) -> bool`

Whether a file exists.

### `env.get`

`get(name: str) -> str? / get(name: str, default: str) -> str`

Reads an environment variable, none when absent (or the default).

### `env.args`

`args: list[str]`

Command-line arguments, including the program name at index 0.

## Methods (SPEC.md section 12.4)

Methods on values. The receiver type is shown first.

### `str`

- `str.upper() -> str`: Uppercase copy.
- `str.lower() -> str`: Lowercase copy.
- `str.strip() -> str`: Copy with leading and trailing whitespace removed.
- `str.split(x: str) -> list[str]`: Splits on the separator.
- `str.join(x: list[str]) -> str`: Joins a list of strs with this string between them.
- `str.contains(x: str) -> bool`: Whether the string contains the argument.
- `str.starts_with(x: str) -> bool`: Whether the string starts with the argument.
- `str.ends_with(x: str) -> bool`: Whether the string ends with the argument.
- `str.chars() -> list[str]`: One Unicode code point per element.

### `list[T]`

- `list[T].append(x: T) -> none`: Appends an element.
- `list[T].contains(x: T) -> bool`: Whether the list contains the element.
- `list[T].get(x: int, a: T) -> T`: Element at the index, or the default when out of range.
- `list[T].len() -> int`: Number of elements.

### `dict[str, T]`

- `dict[str, T].keys() -> list[str]`: Keys in insertion order.
- `dict[str, T].get(x: str, a: V) -> V`: Value for the key, or the default when absent.
- `dict[str, T].contains(x: str) -> bool`: Whether the dict has the key.

### `set[T]`

- `set[T].add(x: T) -> none`: Adds an element.
- `set[T].remove(x: T) -> none`: Removes an element.
- `set[T].contains(x: T) -> bool`: Whether the set contains the element.

### `T?`

- `T?.is_some() -> bool`: Whether the value is present.
- `T?.is_none() -> bool`: Whether the value is absent (none).
- `T?.unwrap() -> T`: The value, or an error when absent.

### `Result[T, E]`

- `Result[T, E].is_ok() -> bool`: Whether the Result is ok.
- `Result[T, E].is_err() -> bool`: Whether the Result is err.
- `Result[T, E].unwrap() -> T`: The ok value, or an error when err.
- `Result[T, E].unwrap_or(x: T) -> T`: The ok value, or the default when err.
